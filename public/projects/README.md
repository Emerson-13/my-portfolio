Place project screenshots in this structure:

public/
  projects/
    hris/
      1.png
      2.png
    lending/
      1.png
    bayadmo/
      1.png

The folder name should match the project key used in `src/data/projects.js`.
Use `1`, `2`, `3`, and so on for multiple screenshots.

Examples already used:
- `public/projects/vyblinx/1.png`
- `public/projects/work4u/1.png`
- `public/projects/payroll/1.png`
- `public/projects/unyryde/1.png`
- `public/projects/barangay/1.jpg`
